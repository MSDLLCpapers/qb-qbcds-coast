## Running COAST on a single-cell RNA-seq dataset

The accession number for the sequencing data used in this paper is GEO: GSE87544.

`preprocess.R` contains the code to preprocess the data prior to running COAST.

`de_analysis.py` contains the code to perform differential gene expression analysis.

`analysis.ipynb` contains the code to run COAST on the sequencing data of two cell states.
