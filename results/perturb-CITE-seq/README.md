## Running COAST on a Perturb-CITE-seq dataset

The Perturb–CITE-seq data can be obtained from [https://doi.org/10.1038/s41588-021-00779-1](https://doi.org/10.1038/s41588-021-00779-1).

We followed the code from uhlerlab/actlearn_optint: v1 ([https://doi.org/10.5281/zenodo.8170179](https://doi.org/10.5281/zenodo.8170179))
to preprocess the data. Additional preprocessing steps are shown in `process_data.ipynb`.

`analysis.ipynb` contains the code to run COAST in three case studies.
`analysis-constraints.ipynb` contains the code to run COAST with two different types of constraints in the three case studies.
